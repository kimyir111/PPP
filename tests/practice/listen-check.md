# G11a-4 듣기 확인 (약 10분, 곡 3개)

무엇을 확인하나: `?practice=graph` 로 열면 연습 화면이 **악보에 적힌 대로** 연주합니다.

| 고친 것 | 이전(기존 재생기) | `?practice=graph` |
| --- | --- | --- |
| D.C. / D.S. / Fine / Coda | 무시하고 악보 끝에서 멈춤 | 표시대로 되돌아가고 Fine에서 끝남 (처음 한 번만, 돌아갈 때 반복 기호는 건너뜀) |
| 꾸밈음 | 소리 안 남 | 소리가 나고 건반 화면에 **작은(가는) 막대**로 보임. 채점에는 **안 들어감** |
| 따라가기 모드 | 반복 구간을 한 번만 물음 | 재생과 **같은 횟수**, **같은 음**을 물음 |
| 이음줄(타이) 뒤 음이 "어디서도 이어지지 않는" 경우 | 따라가기에서 건너뜀 | 재생이 치는 음이니 따라가기도 물음 |

기본값은 아직 바뀌지 **않았습니다**(`legacy`). 아래는 모두 주소에 `?practice=graph` 를 붙여서만 일어납니다.

## 0. 여는 법

**배포 후**: 서비스 주소 뒤에 `?practice=graph` 를 붙입니다.
예) `<서비스 주소>/?practice=graph` (그 방문에서만 적용되고 기억되지 않습니다. 기억시키려면 콘솔에서 `PPP.practice = 'graph'`)

**지금(이 브랜치, 내 PC)**: PowerShell 에서

```
cd D:\PPP-g11a4
$env:NODE_ENV='production'; $env:HOST='127.0.0.1'; $env:PORT='9810'; $env:NODE_PATH='D:\PPP\node_modules'
node server.js
```

브라우저에서 `http://127.0.0.1:9810/Piano%20Coach%20App.dc.html?practice=graph`

열렸는지 확인: F12 → 콘솔에 `PPP.practice` 를 입력하면 `"graph"` 가 나옵니다.
(`PPP.practiceStats` 에서 `jumps`, `graces` 숫자가 올라가면 그 곡에서 해당 기능이 작동한 것입니다.)

## 1. D.C. al Fine — 부르크뮐러 25, 6번 〈Progrès〉

- 위치: 왼쪽 메뉴 **교재 진도** → **부르크뮐러 25** → **6번**
- 파일: `catalog/method/burgmuller25/006.mxl` (16마디, 4/4, ♩=132)
- 화면: **연습** → **처음부터 끝까지** → 재생
- 귀로 볼 것
  1. 1–8마디가 두 번(반복), 9–16마디, 그리고 **16마디 끝의 D.C.** 에서 **1마디로 돌아가** 8마디(Fine)에서 끝나는지.
     돌아갈 때는 1–8마디를 **한 번만** 연주합니다(반복 안 함).
  2. 끝나는 곳이 8마디의 마지막 음인지(곡이 갑자기 끊기지 않는지).
- 이전 길이: 24마디 분량 (약 44초). 이제: 32마디 분량 (약 58초).
- 막대(마디 번호)가 16 → 1 로 돌아가고, 1–8 이 한 번 더 지나가면 정상.

## 2. 꾸밈음 — 부르크뮐러 25, 3번 〈La pastorale〉

- 위치: **교재 진도** → **부르크뮐러 25** → **3번**
- 파일: `catalog/method/burgmuller25/003.mxl` (29마디, 6/8, ♩=100)
- 꾸밈음이 있는 마디: **3, 5, 7, 19, 21, 26, 27**
  (3·7·19·26·27 = 빗금 있는 짧은 앞꾸밈음, 5·21 = 빗금 없는 둘 이어진 앞꾸밈음)
- 화면: **연습** → **구간 반복** 으로 3–5마디를 골라 반복 재생
- 귀로 볼 것
  1. 빗금 있는 꾸밈음은 **박 직전에 아주 짧게** 들리고, 앞 음이 그만큼 짧아집니다.
  2. 빗금 없는 둘 이어진 꾸밈음은 **박에 놓이고** 본음이 그만큼 늦게 들어옵니다 (본음 길이의 절반 이내).
  3. 건반 화면(떨어지는 음표)에 꾸밈음이 **가는 막대**로 나옵니다.
- MIDI 건반이 있으면: 꾸밈음을 **치든 안 치든** 틀린 음으로 세지 않습니다. (본음만 채점)

## 3. 반복과 1·2번 괄호 + 따라가기 — 부르크뮐러 25, 21번 〈L'harmonie des anges〉

- 위치: **교재 진도** → **부르크뮐러 25** → **21번**
- 파일: `catalog/method/burgmuller25/021.mxl` (33마디, 4/4, ♩=130)
- 구조: 1–8 반복, 9–23 + **1번 괄호(24마디)** 반복, **2번 괄호(25마디)** → 33마디
- 재생에서: 변화 없음 (이 곡은 D.C. 도 꾸밈음도 없습니다). 반복·괄호가 이전과 **똑같이** 들리면 정상.
- **따라가기**(MIDI 건반 필요, 버튼 `따라가기`) 에서
  1. 1–8마디를 **두 번** 묻는지 (전에는 한 번만 물었음).
  2. 9–23마디도 두 번, 24마디(1번 괄호)는 첫 번째에만, 25마디(2번 괄호)는 두 번째에만.
  3. **26–29마디 왼손**의 이음줄 뒤 음(8개)을 묻는지 — 재생에서는 이 음이 소리 납니다.

## 선택: D.S. al Coda (손으로 만든 곡)

카탈로그에는 D.S.가 든 곡이 없어서 시험용 파일을 씁니다.
`tests/practice/fixtures/parity/ds-al-coda-repeat-volta.musicxml` 를 **불러오기** 로 올려서 `?practice=graph` 로 재생하세요.
(9마디. 순서: `1 2 3 4 | 2 3 5 6 | 2 3 5 → 코다 7 8 9`.)
6마디 끝의 D5 는 7마디로 이어진 음이지만, 코다로 갈 땐 이어지지 않으므로 **7마디 첫 D5 를 다시 칩니다**.

## 이상하면: 되돌리는 법

| 하고 싶은 것 | 방법 |
| --- | --- |
| 전부 원래대로 | 주소에서 `?practice=graph` 를 지우고 새로고침 (기본값은 `legacy`) |
| graph 재생기는 쓰되 네 가지 고침만 끄기 | `?practice=graph&practiceFix=off` |
| 꾸밈음만 끄기 | `?practice=graph&practiceFix=jumps,repeats,ties` |
| D.C./D.S. 만 끄기 | `?practice=graph&practiceFix=graces,repeats,ties` |
| 따라가기의 반복/이음줄만 끄기 | `?practice=graph&practiceFix=jumps,graces` |

(`jumps` = D.C./D.S./Fine/Coda, `graces` = 꾸밈음, `repeats` = 따라가기 반복, `ties` = 따라가기 이음줄.
콘솔에서 `PPP.practiceFix = 'off'` 로 바꾸면 이 기기에 기억됩니다. `PPP.practiceFix = null` 로 기본값으로 돌아갑니다.)

## 알아 둘 것

- **구간 반복에 D.C. 가 들어 있으면** (예: 부르크뮐러 6번 13–16마디) D.C. 는 *구간의 처음*으로 돌아가므로 한 번 반복에 같은 구간이 두 번 연주됩니다. 반복 기호가 구간 끝에 있을 때 두 번 연주되는 것(기존)과 같은 규칙입니다. 거슬리면 알려 주세요.
- 일시정지한 곳이 **두 번 지나가는 마디**이면, 이제 다시 누를 때 *그 번째*에서 이어집니다.
- 이 확인은 **재생 기본값을 바꾸지 않습니다.** 괜찮다고 하시면 기본값 전환(G11a-5)은 따로 말씀해 주세요.
